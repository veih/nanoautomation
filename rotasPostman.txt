Rotas da API para Teste com Postman
1. CMs (Centrais de Monitoramento)
Base URL: http://localhost:3000/api/cms

Listar todos os CMs:

Método: GET

URL: http://localhost:3000/api/cms

Exemplo de Resposta:

[
  {
    "id": "uuid-do-cm-1",
    "nome": "CM Principal",
    "localizacao": "Edifício Central",
    "equipamentos": [
      // ... equipamentos relacionados
    ]
  },
  {
    "id": "uuid-do-cm-2",
    "nome": "CM Secundário",
    "localizacao": "Anexo 2"
  }
]

Obter CM por ID:

Método: GET

URL: http://localhost:3000/api/cms/{id}

Exemplo: http://localhost:3000/api/cms/uuid-do-cm-1

Exemplo de Resposta:

{
  "id": "uuid-do-cm-1",
  "nome": "CM Principal",
  "localizacao": "Edifício Central",
  "equipamentos": [
    // ... equipamentos relacionados
  ]
}

Criar novo CM:

Método: POST

URL: http://localhost:3000/api/cms

Body (JSON):

{
  "nome": "CM Nordeste",
  "localizacao": "Fortaleza, CE"
}

Exemplo de Resposta:

{
  "id": "novo-uuid-gerado",
  "nome": "CM Nordeste",
  "localizacao": "Fortaleza, CE"
}

Atualizar CM existente:

Método: PUT

URL: http://localhost:3000/api/cms/{id}

Exemplo: http://localhost:3000/api/cms/uuid-do-cm-1

Body (JSON): (Envie apenas os campos que deseja atualizar)

{
  "localizacao": "Edifício Principal - Sala 101"
}

Exemplo de Resposta:

{
  "id": "uuid-do-cm-1",
  "nome": "CM Principal",
  "localizacao": "Edifício Principal - Sala 101",
  "equipamentos": []
}

Deletar CM:

Método: DELETE

URL: http://localhost:3000/api/cms/{id}

Exemplo: http://localhost:3000/api/cms/uuid-do-cm-a-deletar

Exemplo de Resposta: Status 204 No Content (corpo vazio)

2. Equipamentos
Base URL: http://localhost:3000/api/equipamentos

Listar todos os Equipamentos:

Método: GET

URL: http://localhost:3000/api/equipamentos

Exemplo de Resposta:

[
  {
    "id": "uuid-do-equipamento-1",
    "nome": "Servidor Principal",
    "descricao": "Servidor de dados central",
    "cmId": "uuid-do-cm-1",
    "cm": { /* ... dados do CM */ },
    "atuadores": [],
    "sensores": []
  }
]

Obter Equipamento por ID:

Método: GET

URL: http://localhost:3000/api/equipamentos/{id}

Exemplo: http://localhost:3000/api/equipamentos/uuid-do-equipamento-1

Exemplo de Resposta:

{
  "id": "uuid-do-equipamento-1",
  "nome": "Servidor Principal",
  "descricao": "Servidor de dados central",
  "cmId": "uuid-do-cm-1",
  "cm": { /* ... dados do CM */ },
  "atuadores": [
    // ... atuadores relacionados
  ],
  "sensores": [
    // ... sensores relacionados
  ]
}

Criar novo Equipamento:

Método: POST

URL: http://localhost:3000/api/equipamentos

Body (JSON):

{
  "nome": "Sensor de Temperatura Sala A",
  "descricao": "Monitora a temperatura ambiente",
  "cmId": "uuid-do-cm-existente"
}

Exemplo de Resposta:

{
  "id": "novo-uuid-gerado",
  "nome": "Sensor de Temperatura Sala A",
  "descricao": "Monitora a temperatura ambiente",
  "cmId": "uuid-do-cm-existente"
}

Atualizar Equipamento existente:

Método: PUT

URL: http://localhost:3000/api/equipamentos/{id}

Exemplo: http://localhost:3000/api/equipamentos/uuid-do-equipamento-1

Body (JSON):

{
  "descricao": "Servidor de dados central atualizado",
  "cmId": "outro-uuid-do-cm-existente"
}

Exemplo de Resposta:

{
  "id": "uuid-do-equipamento-1",
  "nome": "Servidor Principal",
  "descricao": "Servidor de dados central atualizado",
  "cmId": "outro-uuid-do-cm-existente",
  "cm": { /* ... dados do novo CM */ },
  "atuadores": [],
  "sensores": []
}

Deletar Equipamento:

Método: DELETE

URL: http://localhost:3000/api/equipamentos/{id}

Exemplo: http://localhost:3000/api/equipamentos/uuid-do-equipamento-a-deletar

Exemplo de Resposta: Status 204 No Content
